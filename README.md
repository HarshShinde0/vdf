# Croissant Vocabulary Definition Files (VDF)

This directory hosts the compiled machine-readable vocabulary definitions and developer portal assets for the Croissant specification.

## Directory Structure

- **`developers.html`**: Main Schema.org-styled landing page for developers.
- **`types.html`**: Term reference page listing Class (Type) definitions.
- **`properties.html`**: Term reference page listing Property definitions.
- **`context-http.json` / `context-https.json`**: Canonical JSON-LD contexts matching the `mlcroissant` specifications.
- **`croissant-*.{ttl, jsonld, rdf, nt, nq, csv}`**: Serialized formats of the vocabulary definitions (Core, Geo, RAI, and Combined) in both `http` and `https` schema.org flavors.
