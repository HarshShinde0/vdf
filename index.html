Croissant for Developers

This page provides developer-oriented information about Croissant and access to machine-readable representations of the vocabulary.

Machine Readable Term Definitions

  • Source files are maintained in Turtle format in our Github repository.
  • Croissant builds on schema.org and its Dataset vocabulary.
  • Schema.org URIs are available in both http and https. Croissant namespace URIs (cr:, geo:, rai:) always use http://.
  • The canonical JSON-LD Context files are available at context-http.json and context-https.json.
  • View all terms on the Classes (Types) and Properties pages.
